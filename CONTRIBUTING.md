# Contributing

This is a small public app. Useful changes:

- Correct a title’s service, episode count, or facts for the US catalog
- Add a flagship series that is missing from one of the nine services
- Improve the Jev question wording or the heuristic fallback
- Fix physics, accessibility, or mobile layout

Please keep the interaction: one sentence in, every title considered, matches rise.

```bash
npm install
npm test
npm run build
```

Do not commit `.env.local` or API keys.
